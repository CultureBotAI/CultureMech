   merged as duplicate recipes, then regenerate the bacterial ASW barley outputs
   so C6, C7, and C8 each keep their own generated record.

   retain them only as salinity variants.
3. Add structured provenance for MediaDive C8 and preserve the older CCAP C8
   source behind the barley step, or flag the current CCAP `MR_ASW_300.pdf` as a
   drifted salt-only source.
4. Decide whether barley grains should be an explicit undefined ingredient,
   then update `composition_type` and the C6/C7/C8 preparation/component model
   consistently.
5. Normalize the C6/C7/C8 preparation strings so carriage returns and soft
   hyphens do not leak into generated YAML.
