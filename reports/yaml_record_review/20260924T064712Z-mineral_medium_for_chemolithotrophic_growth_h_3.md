## Evidence

MediaDive Medium 81 defines a 1 L main solution assembled from 50 ml Solution A, 925 ml Solution B, 20 ml Solution C, and 5 ml Standard vitamin solution. Solution A is a 50 ml phosphate stock with 2.3 g KH2PO4, 2.9 g Na2HPO4 x 2 H2O, and 50 ml water. Solution B is a 925 ml stock with NH4Cl, MgSO4 x 7 H2O, CaCl2 x 2 H2O, 5 mg MnCl2 x 4 H2O, 5 mg NaVO3 x H2O, 5 ml Trace element solution SL-6, water, and 20 g agar if required. Solution C is a 20 ml ferric ammonium citrate stock.

The YAML stores the stock-normalized values directly: 46 g/L KH2PO4 and 58 g/L Na2HPO4 x 2 H2O from the 50 ml Solution A, 1.08696 g/L NH4Cl and 0.543478 g/L MgSO4 x 7 H2O from the 925 ml Solution B, 2.5 g/L ferric ammonium citrate from the 20 ml Solution C, and 21.7391 g/L agar from Solution B. Those values describe subsolutions, not the final 1 L assembled medium.

MediaDive defines Standard vitamin solution as a separate 100 ml stock containing riboflavin, thiamine-HCl x 2 H2O, nicotinic acid, pyridoxine hydrochloride, calcium pantothenate, biotin, folic acid, vitamin B12, and water. It defines Trace element solution SL-6 as a 1 L stock containing ZnSO4 x 7 H2O, MnCl2 x 4 H2O, H3BO3, CoCl2 x 6 H2O, CuCl2 x 2 H2O, NiCl2 x 6 H2O, Na2MoO4 x 2 H2O, and water.
