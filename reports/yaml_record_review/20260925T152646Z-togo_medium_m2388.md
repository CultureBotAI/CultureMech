## Identity and Grounding

The record is the TOGO M2388 bicarbonate-buffered synthetic crenarchaeota medium.
The `TOGO:M2388` media term and the target ID agree. Its formulation, however,
is split in TOGO into a main per-liter medium and a nested `Trace element
solution (per liter)`. The generated record collapses those boundaries.

The trace stock link is not formulation-compatible. TOGO M2388's trace stock
contains Na2MoO4 x 2H2O, H3BO3, MnCl2 x 4H2O, CoCl2 x 6H2O, NiCl2 x 6H2O,
ZnSO4 x 7H2O, CuCl2 x 2H2O, and concentrated HCl. The current
`mediadive.solution:6187` target is a different trace element solution built
around Na2-EDTA, FeCl3 x 6H2O, MnCl2 x 4H2O, ZnCl2 x 6H2O, CoCl2 x 6H2O, and
Na2MoO4 x 2H2O.
