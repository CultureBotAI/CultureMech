original DSMZ PDF text. It computes expected stage-specific nodes and amounts
without importing the builder or treating its proposed hashes as scientific
proof. It checks all old quantity fields, exact row identity, expected new
nodes, scoped evidence, bibliography, unchanged annotations and append-only
history. The original PDF page was also visually inspected.

Tests deliberately invent an amount at every one of the 138 output nodes and
recompute the proposed serialized hash. These mutations must still fail the
independent source projection. Other attacks omit/add ingredients, invent
grounding and snippets, rewrite history, corrupt old values, drop claims or
lineage, invent bibliography years/titles, and alter permanent IDs.

supplements, unknown variant pH, separate stock boundaries and liquid input
units, existing qualified evidence paths, and the unchanged comparison and
inaccessible records. The successor adds ten deterministic rebuild tests,
sixteen unexpected parent/child mutation cases and guarded write/readback/no-op,
concurrent target/comparison edit, symlink and pinned-plan tests. The independent
auditor checks exact linked names and rejects unrelated relationship mutations.
Application requires the frozen review receipt and exact plan hash; it refuses
unreviewed plan changes or source-record drift.
