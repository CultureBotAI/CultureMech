# Medium436 Adversarial Review

The independent auditor reparses KOMODO HTML, MediaDive/TOGO JSON and the
original DSMZ PDF text. It computes expected stage-specific nodes and amounts
without importing the builder or treating its proposed hashes as scientific
proof. It checks all old quantity fields, exact row identity, expected new
nodes, scoped evidence, bibliography, unchanged annotations and append-only
history. The original PDF page was also visually inspected.

Tests deliberately invent an amount at every one of the 138 output nodes and
recompute the proposed serialized hash. These mutations must still fail the
independent source projection. Other attacks omit/add ingredients, invent
grounding and snippets, rewrite history, corrupt old values, drop claims or
lineage, invent bibliography years/titles, and alter permanent IDs.

Domain checks preserve KOMODO Gram Amount precision/nulls, both variant
supplements, unknown variant pH, separate stock boundaries and liquid input
units, existing qualified evidence paths, and the unchanged comparison and
inaccessible records. Application and verification modes currently fail closed;
guarded write/readback/no-op fixtures are still required before enabling them.

The first builder attempt stopped because its guard expected `PH Info: 7`
instead of the source's exact `PH Info: 7.0`; no plan or recipe write occurred.
The corrected preview is frozen separately. Source inspection also showed that
KOMODO3017's conflicting DSMZ3017 link is present in the provider Instructions,
not demonstrably just an importer-generated error. The preview records that
actual conflict. A temporary gate helper's parenthesis typo was corrected
before it created any receipt; it did not change a recipe or proposal.

The initial targeted suite passed 263 tests. The broader focused suite passed
535 tests with two dependency warnings; all 20 preview schema/strict commands,
179 capture-backed reference checks, lint and formatting passed. All receipts
for these checks are terminal. Independent/source checks do not resolve
unknown scientific bases, certify all unrelated metadata, or prove that the
entire corpus is complete.
