# Adversarial Review

The independent auditor reads the original frozen HTML/JSON/PDF text captures,
not the builder's row decisions. It projects every output ingredient, quantity,
stage, field path and allowed identity change; checks exact quotations and
claim-to-evidence linkage; preserves old evidence and history; and validates
reciprocal family relationships and unrelated metadata.

Tests attack every proposed node with an invented quantity even after rehashing
the output. Additional cases remove or add nodes, corrupt snippets, titles,
years, old values, history, IDs, claims, lineage and unrelated parent/child
links. Specific tests cover the nominal final denominator, variant rates,
mg inputs, two water stages, seven linked VFA rows, stock makeup, resazurin
strength, prior evidence paths and inaccessible-original boundaries.

The first development attempt stopped before writing a plan because it compared
the parent medium's stock rows to the standalone API rows byte-for-byte: the
standalone API includes explicit null keys that the parent omits. The successor
compares every non-null key/value, in order, and still requires exact stock id,
title and row count. It does not tolerate a changed quantity or a missing
non-null field. This was a guard mismatch, not a source amount disagreement.

Manual review also moved the salt-grounding withdrawal rationale into the
quantity/identity evidence explanations and removed a stock-water assertion
from an unrelated main-preparation excerpt. Stock-water evidence remains on
the actual stock rows. The independent auditor verifies the seven literal
JCM133 VFA row identities, amounts and units separately from TOGO's row order.

all 26 historical preview schema/strict commands pass. The frozen preview retains

tampering, concurrent edits, symlinks, readback and no-op. Independent cumulative
audit registration is covered by additional tests, including rehashed mutations.
