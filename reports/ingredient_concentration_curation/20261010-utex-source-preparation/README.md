# UTEX Source Preparation

Captured 64 public UTEX recipe pages on 2026-10-10, one request per second, using
the source accessions of current records outside canonical follow-up coverage.
The seven separately reviewed soil/seawater proposals are excluded. The selected
records contain 818 existing concentration claim rows.

[Source manifest](source-captures.json) records original and effective URLs,
access times, page titles, raw-capture hashes, recipe text, table cells, parsed
components and links. All 64 pages returned a recipe container and composition
table. Raw HTML captures remain outside the repository in the manifest's paths.
The repository's maintained UTEX table parser supplies candidate components;
parser output is not scientific evidence verification.

**Source collection only: zero completed scientific reviews, zero authoritative
record edits and zero canonical coverage increment.** Record hashes were checked
before and after collection. Formulation matching, chemical forms, units, volume
bases, linked stock sources, bibliographic metadata and every individual claim
still require review. No DOI, authors or publication year are inferred.

reviews Malt, Euglena, Polytomella, Ochromonas and Trebouxia, including the separately
retrieved liver-extract stock source. That review is unapplied and does not
rewrite this historical collection manifest or add canonical coverage. A further
[six-blend preview](../20261010-utex-six-blends-preview/README.md) reviews twelve
input doses and retains the quarter-strength Erdschreiber source ratio conflict.
A further [five-soilwater conflict review](../20261010-utex-five-soilwater-conflicts-preview/README.md)
checks thirteen claims but withholds mutations pending source/formulation
decisions. Forty-eight of the captured records still have source preparation
only. All sixteen subsequently reviewed records remain unchanged; none adds
canonical coverage yet.
